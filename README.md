# 개인 포트폴리오

GitHub Pages에 바로 올릴 수 있는 정적 포트폴리오입니다. 빌드 과정이 필요하지 않습니다.

## 내용 바꾸기

`index.html`에서 다음 임시 문구를 실제 정보로 바꿔 주세요.

- 이름, 직무 및 한 줄 소개
- 소개와 주요 역량
- 프로젝트 이름, 설명, 분야, 연도 및 링크
- 수상 내역, 자격증, 논문·개인 연구, 활동
- 이메일 주소와 GitHub 프로필 주소

프로젝트 링크는 현재 연락하기 섹션으로 연결되어 있습니다. 실제 프로젝트 주소가 준비되면 각 `project-link`의 `href`를 바꿔 주세요.

## 미리보기

이 폴더에서 `python -m http.server 4173`을 실행하고 `http://localhost:4173`을 여세요.

## GitHub Pages 배포

1. GitHub에 공개 저장소를 만들고 이 폴더의 파일을 저장소 최상위에 올립니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치를 `main`, 폴더를 `/ (root)`로 설정하고 저장합니다.
4. 몇 분 뒤 Pages 화면에 표시되는 주소를 확인합니다.

저장소 이름이 `<사용자명>.github.io`라면 주소는 `https://<사용자명>.github.io/`입니다. 다른 저장소 이름이라면 `https://<사용자명>.github.io/<저장소명>/`입니다.
