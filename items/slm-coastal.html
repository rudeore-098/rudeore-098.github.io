SLM 기반 해안 경계 이벤트 위험도 분류

이선홍, 최원석, 이우준, 김유찬

Paper (PDF)

해안 경계 이벤트를 위험·정상으로 분류하고 짧은 상황 보고문을 생성하는 소형 언어모델을 만들었습니다. QLoRA로 미세조정한 모델의 매크로 F1은 0.9461로, 기준 모델(0.6007)보다 크게 높았습니다.

초록

이 연구는 해안 경계 이벤트를 분류하고 간략한 상황 보고문을 생성하는 SLM 기반 모델을 제안합니다. 일반화한 이벤트 샘플 926개로 데이터셋을 만들어 학습·검증·테스트 데이터로 나누었습니다. QLoRA 기반 PEFT 모델이 기준 모델보다 높은 성능을 보여, 위험 탐지와 보고를 자동화할 가능성을 확인했습니다.

연구 과정

  1. 데이터 구축위험 라벨과 상황 보고문이 붙은 지시문 형식 샘플 926개
  2. 일반화와 검토기밀·민감 정보를 빼고 해병대 인원이 검토
  3. 데이터 분할학습·검증·테스트를 8:1:1로 분할
  4. 기준 모델 평가kanana-1.5-2.1b-instruct를 추가 학습 없이 평가
  5. QLoRA 미세조정같은 테스트 세트에서 기준 모델과 비교
